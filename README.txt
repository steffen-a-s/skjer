SKJER – automatisk innhenting v1

1. Last opp hele denne mappen til Netlify-prosjektet ditt.
2. Netlify bruker netlify.toml til å finne Functions.
3. collect-events.js er laget som en Scheduled Function.
4. Første versjon henter USF Verftet + Loppi.
5. Netlify Blobs lagrer siste resultat.

Viktig:
Dette er første tekniske steg. USF og Loppi har ulike sidetyper, så parseren bør forbedres etter første test før vi stoler på den som komplett arrangementskalender.
